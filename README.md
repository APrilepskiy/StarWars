# ⭐ Star Wars Shooter — «Звёздные войны» на Java 🚀

Космический аркадный шутер, написанный на **Java (Swing/AWT)** без сторонних библиотек.

Вы пилотируете небольшой звёздный истребитель и сбиваете приближающиеся вражеские
TIE Fighter. Чем выше счёт — тем быстрее и чаще появляются враги.

## 🎮 Управление

| Клавиша            | Действие                |
|--------------------|-------------------------|
| `↑ ↓ ← →` стрелки | Полёт самолётика        |
| `Пробел`           | Стрельба (лазерами)     |
| `Enter`            | Рестарт после Game Over |

## ✨ Возможности

- Плавный игровой цикл 60 FPS с двойной буферизацией (без мерцания);
- Враги TIE Fighter, летящие сверху вниз со случайным дрейфом;
- Нарастающая сложность: скорость и частота появления врагов растут со счётом;
- Лазерная стрельба, столкновения, анимированные взрывы частицами;
- Скроллящийся звёздный фон (эффект полёта в гиперпространстве);
- Счёт и рекорд, экран **GAME OVER** с рестартом по `Enter`.

## 🚀 Как запустить

Нужна установленная **JDK 8+** (рекомендуется JDK 17).

### Вариант 1 — просто скриптом

```bash
# Linux / macOS
./run.sh
```

```bat
:: Windows
run.bat
```

### Вариант 2 — команды вручную

```bash
mkdir -p bin
javac -encoding UTF-8 -d bin src/starwars/StarWarsGame.java
java -cp bin starwars.StarWarsGame
```

### Вариант 3 — Maven (соберётся исполняемый JAR)

```bash
mvn package
java -jar target/star-wars-shooter-1.0.0.jar
```

## 🖥️ Важно про «работу в браузере»

Java-приложения **не запускаются в современных браузерах** (технология
Java Applet / Java Web Start объявлена устаревшей и удалена из всех основных
браузеров ещё в 2016–2019 гг.). Поэтому игра запускается **локально** командой
`java` или скриптом `run.sh` / `run.bat` — это стандартный способ для Java.

Игра полностью кроссплатформенная: работает на **Windows, macOS и Linux**
(Swing входит в состав стандартной JDK, дополнительных зависимостей нет).

Если браузерный запуск критичен — игру можно перенести на JavaScript/Canvas
с сохранением всей логики.
